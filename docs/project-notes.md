# Project Notes — Custom Loan Management Web Application

## Overview

This project is a custom web-based loan management system developed for a real business client. It centralizes customer management, loan applications and agreements, payments, ledger records, receipts, reporting, and staff access within one application.

## My Role

I developed the system as an independent / freelance full-stack developer, covering the application structure, backend development, frontend implementation, database integration, business workflows, and supporting documentation.

## Main Features

- Customer pre-registration and application review
- Customer profile and document management
- Loan and agreement management
- Payment recording and receipt generation
- Internal and official ledger workflows
- Reports and document generation
- Role-based staff access and authentication
- Activity logging and notifications
- Global search
- Multi-company / business-context switching
- Message templates and WhatsApp-related workflows

## Technology

- Python
- Django 6
- HTML
- CSS
- JavaScript
- SQLite
- Django authentication and role-based permissions
- ReportLab / document-generation tools

## Architecture

The application follows a Django-based web architecture. Users access the system through a web browser, while Django handles authentication, business logic, data processing, reporting, and communication with the database.

See the system architecture diagram in this repository for a visual overview.
